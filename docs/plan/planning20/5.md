### GROUP 5 — B1: Task 5 tầng + Task Profile (~2-3 ngày)

> Lớn nhất, ảnh hưởng toàn bộ task system

#### Yêu cầu nghiệp vụ (confirmed 2026-05-22)

- **5 tầng task**: level 0 (task gốc) → level 1 → level 2 → level 3 → level 4
- **TaskProfile = mẫu cây task tái sử dụng**:
  - User define xong cây task trong 1 dự án → nhấn "Lưu làm mẫu" → tạo TaskProfile
  - Profile lưu: **cấu trúc cây** (tên task, thứ tự, parent-child) + **`duration_days`** mỗi task
  - Profile là **global** (dùng được cho mọi dự án, không khóa theo project)
  - Khi apply vào dự án mới: tạo cây task với tên sẵn, `duration_days` làm gợi ý; **user tự set ngày start/end** — không auto-tính
  - Duration không phải offset, chỉ là số ngày tham khảo (ví dụ task A1A = 6 ngày)

#### Tên 5 tầng (confirmed 2026-05-22)

| Level | Tên hiển thị | Màu gợi ý |
|-------|-------------|-----------|
| 0 | **Hạng mục** | xanh đậm (blue-700) |
| 1 | **Công việc** | xanh trung (blue-500) |
| 2 | **Đầu việc** | xanh nhạt (cyan-600) |
| 3 | **Bước** | slate-600 |
| 4 | **Chi tiết** | slate-400 |

**B1b — Model TaskProfile + TaskProfileItem**
- File: `backend/app/models/task.py`

```python
class TaskProfile(SQLModel, table=True):
    id: uuid.UUID  # PK
    name: str              # tên mẫu
    description: str | None
    created_by: uuid.UUID  # FK user
    created_at: datetime

class TaskProfileItem(SQLModel, table=True):
    id: uuid.UUID  # PK
    profile_id: uuid.UUID  # FK TaskProfile (cascade delete)
    parent_item_id: uuid.UUID | None  # self-ref (cây trong profile)
    name: str
    level: int             # 0–4
    duration_days: int     # số ngày làm việc
    order_index: int       # thứ tự trong cùng parent
    description: str | None
    module_tag: str | None
    color: str | None
```

Public schemas: `TaskProfilePublic`, `TaskProfileItemPublic`, `TaskProfileCreate`, `TaskProfileItemCreate`

**B1c — Migration `0028_task_profile.py`**
- `down_revision = "0027_quotation_approval_participants"`
- Tạo 2 bảng: `taskprofile`, `taskprofileitem`

**B1d — Endpoints**

| Method | Path | Mô tả |
|--------|------|-------|
| GET | `/task-profiles/` | Danh sách tất cả profile |
| POST | `/task-profiles/` | Tạo profile mới (rỗng) |
| GET | `/task-profiles/{id}` | Chi tiết 1 profile + items |
| PATCH | `/task-profiles/{id}` | Cập nhật tên/mô tả |
| DELETE | `/task-profiles/{id}` | Xóa profile |
| POST | `/task-profiles/{id}/items` | Thêm item vào profile |
| PATCH | `/task-profiles/items/{item_id}` | Sửa item |
| DELETE | `/task-profiles/items/{item_id}` | Xóa item |
| **POST** | `/task-profiles/{id}/apply` | Apply profile vào project → tạo cây task |

**Apply logic** (`POST /task-profiles/{id}/apply`):
- Body: `{ project_id, parent_task_id: uuid | null, assignee_id }`
- Nếu `parent_task_id = null` → tạo ở level 0 (Hạng mục)
- Nếu có `parent_task_id` → kiểm tra `parent.level + profile_root.level <= 4`
- Tạo toàn bộ cây task, `start_time = end_time = now` (placeholder — user sẽ tự sửa ngày)
- Trả về: list task đã tạo

**Save-from-task logic** (`POST /tasks/{id}/save-as-profile`):
- Body: `{ name, description? }`
- Đọc cây task con từ task gốc (đệ quy)
- Tính `duration_days = (end_time - start_time).days` cho từng item
- Tạo profile + items, trả về `TaskProfilePublic`
